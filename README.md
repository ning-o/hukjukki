# 메랜 흑적기 -MVP버전
**메이플랜드 게임 사용자를 위한 사냥 효율 계산기 및 버프 매니저**

비전공자로서 파이썬과 웹 프론트엔드 수업을 들으며, 학습 목적과 더불어 제가 실제로 플레이중인 게임에서 발생하는 불편함을 기술적으로 해결하기 위해 시작한 프로젝트입니다.


## 바로가기
[프로젝트 실행 링크](https://ning-o.github.io/hukjukki/)

## 주요 기능
- **실시간 사냥 정산 (Report):** 1시간당 흑자/적자 계산에 용이
- **스마트 버프 타이머:** 다양한 직업군의 버프 지속 시간을 관리하며, 종료 전 사전 알람 기능 제공.
- **버프 상황판:** 브라우저의 PIP 기술을 활용하여 게임 화면 위에서 버프 시간 확인 가능.

## 기술 스택
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Deployment:** GitHub Pages

## 기술적 난관 및 해결 과정 (Troubleshooting)
### PIP 모드 내 동영상 UI 간섭 문제
- **문제:** 게임 화면 위에 상황판이 가리기 때문에 최소한 데이터만 보여주는 UI로 구현하려 했으나, 기존 비디오 스트림 방식 사용 시 재생 바 등 불필요한 UI가 화면을 가리는 현상 발생.
- **해결:** `Document Picture-in-Picture` API를 연구하여, 비디오가 아닌 웹 요소 자체를 팝업 창으로 분리하는 방식을 채택해 순수 데이터만 노출 성공.

## 향후 업데이트 계획 (Roadmap)
- 사냥터 가성비 분석 시스템

- 보스 레이드 스케쥴러 (보스 타이머)

- 정식 버전 출시 및 명칭 변경
  -UI/UX 고도화 및 베타 태그 제거
  -사용자 설정 저장 기능 안정화


## 업데이트 로그

### v0.3.0 (2026.01.07) - 아키텍처 리펙토링 및 안정화
코드의 유지보수성과 확장성을 위해 전면적인 모듈화 진행
기존 단일 파일 구조에서 기능별 모듈 단위로 분리하여 개발 효율 높임

모듈화를 통한 구조 개선과 함께, 실제 사용 환경에서의 편의 기능 대폭 강화

- **Refactoring**:
  - JS 기능별 모듈 분리 (`Report`, `Buff`, `Logic` 등) 및 ES6 Module 패턴 적용
  - CSS UI 영역별 파일 분할 (`Common`, `Layout`, `Component`)
- **Enhancement (Usability)**:
  - **PIP 모드 지원**: 사냥 타이머를 PIP로 띄워 멀티태스킹 편의성 제공
  - **원클릭 동기화**: 사냥 타이머 시작 시 버프 알리미도 자동으로 동시에 시작되도록 개선
  - **로직 정밀도 향상**: 사용자 직접 입력 데이터 처리 및 예외 처리 로직 강화
  - **상태 동기화**: 모듈 간 이벤트 처리 구조 최적화로 타이머 오차 해결
- **UI/UX**:
  - 입력 폼 레이아웃 조정 및 가독성 개선

- **확장 기능**:
